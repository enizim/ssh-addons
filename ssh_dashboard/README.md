# SSH Smart Home Dashboard

Multi-user smart-home dashboard for Home Assistant.

- Per-user accounts with a PIN (4–10 digits) and per-room permissions, enforced
  server-side
- Rooms, device mapping, and custom icons
- Widgets for lights, climate, covers, media players, valves and sensors
- Security page: smart locks and alarm panel
- Camera wall with full-screen live view and PTZ
- Battery monitoring and activity history
- Mobile apps pair once and carry their own device token — revocable per device
- English and Arabic, with full right-to-left layout
